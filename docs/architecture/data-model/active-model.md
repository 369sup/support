# Active Physical Model

This register covers only contexts whose `implementationStatus` is `active` in
`module-map.json`. The SQL file column points to the exact field-level contract:
it owns column types, nullability, defaults, PK/FK/unique/check constraints,
referential actions, and indexes. Unless a row says otherwise, data is
`internal`, retained while the owning resource exists, erased by the owning
context workflow, and read/written only by `support_web_runtime` through the
named bounded-context adapter.

## Cross-cutting contracts

- `support_private.schema_contract` contains exactly one current application
  contract row. Production composition checks it once before constructing
  adapters.
- Supabase `auth.users` is an external identity authority. Its provisioning and
  email-sync triggers may write only the identity schemas named above.
- The `support-media` Storage bucket is private. Product metadata is in
  `support_platform_media_storage`; Storage objects are not an authorization
  or lifecycle authority by themselves.
- Closed discriminators that still encode an owner or subject variant are
  explicitly transitional. Adding a new discriminator requires a design update,
  a named `CHECK`, test coverage, and a decision on concrete FK feasibility.
